Chat and recall

The latest question queries local memory. Gemini gets the recent conversation and a short readout when a lesson matches.

  1. Qwen2.5-3B

    The frozen model encodes the latest question into features.

  2. Trained recall policy

    Scores the saved lessons and selects compact embedding rows above its recall threshold.

  3. Local vector-to-text readout

    Matches the rows against the pinned Qwen3.6-35B input embedding table and decodes their token IDs.

  4. Remote

    Gemini writes the reply

    Recent chat and the decoded readout arrive as separate inputs. Inspect memory shows what was recalled.

When memory abstains

The readout step is skipped. Gemini receives the ordinary chat context with no added memory.

Dream and consolidation

Use Run Dream to review queued notes and train the local policy. Chat messages queue by default with a per-message opt-out.

  1. Queue research notes

    Bring chat lessons, corrections, preferences, experiment updates, and TXT or Markdown notes.

  2. Remote planning

    Prepare the questions

    Vicena selects grounded lessons and checks Gemini’s practice and held-out questions against those lessons. Dream can fall back to local questions.

  3. Train the recall policy

    Using frozen 3B features, REINFORCE rewards correct recall or abstention. Dream reports measured reward and policy entropy.

  4. Validate and save

    Check recall on held-out questions, abstention on unrelated prompts, and retention of earlier lessons. Save the candidate if it passes.

Planned research

Direct latent handoff

Jointly train the memory reader and a learned connector so the next model can use the vectors directly, without a text readout.

  1. Local memory reader

    Read the question and saved state. Return useful memory vectors or abstain.

  2. Learned connector

    Map vectors into the next model’s input space. Train the reader and connector together using downstream answer quality.

  3. Larger model input

    A compatible runtime inserts the aligned rows alongside the normal prompt embeddings at prefill. The larger model can stay frozen while the reader and connector train.

Alignment

Match the receiver’s embedding width, numeric format, scale, and placement. Test whether the vectors improve its answers on questions held out from training.

Empty or unrelated memory

Pass zero memory rows. The larger model receives its ordinary prompt unchanged, with no added placeholder or embedding.

Existing local 35B experiment

A separately configured Qwen3.6-35B runtime can already ingest its own native embedding rows directly. The web demo loads the pinned input table for the local readout and uses Gemini to answer. Joint training of the reader and connector is still planned.
