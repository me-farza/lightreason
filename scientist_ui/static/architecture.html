System architecture

How a research note becomes something Vicena can recall and apply.

Chat and recall

Recent turns provide short-term context. The local 3B can recall lessons from earlier sessions.

  1. Current chat

    Your question and recent turns supply the conversation context.

  2. Local 3B memory

    Reads the saved policy and returns a compact memory signal when a lesson matches.

  3. Optional · remote

    Gemini synthesis

    Receives the recent chat and a short text readout if local memory recalled something.

  4. Chat reply

    Inspect memory shows the readout when one was used. Wiki lookups and inventory questions stay local.

Chat tools

Ask “Search the wiki for baseline drift” to open matching source notes, or “Which memories do you have?” for the local inventory. Inspect memory shows which steps ran and links to the evidence.

Local 35B vector route

When the matching 35B runtime is configured, the local 3B memory can pass model-compatible vectors into the 35B directly. The 35B writes the reply.

Dream and consolidation

Dream runs when you select Run Dream. It reports the training questions, rewards, and validation checks.

  1. Queue notes

    Chat messages are queued by default with a per-message opt-out. Documents and direct notes can also be queued.

  2. Select lessons

    Identify specific procedures, corrections, experiment outcomes, and preferences.

  3. Train and validate

    Train the local recall policy with rewards for correct actions. Check recall, abstention, and retention.

  4. Save memory

    Save validated updates to disk so a later chat can use them after a restart.

Optional Gemini question planning

When enabled, Dream sends selected note excerpts to Gemini for question variants and wiki organization. Training, validation, and checkpoint storage happen on the local host.

Exact evidence

Dream also files useful approved notes as evidence, including details that never become part of the recall policy.
